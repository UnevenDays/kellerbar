# Kellerbar

Ein Tablet-Spiel für die Nachtschicht. Die Bar ist weiß und blau, Sterne hängen drumherum. Die Gegner heißen Netanjahuuu, tragen Zylinderhüte und wollen die Theke. Du schlägst sie mit dem Baseballschläger benommen oder ziehst sie mit der Peitsche ran und sperrst sie in den Keller.

## Spielen

```bash
npm install
npm run dev
```

Die App läuft auf [http://localhost:4731](http://localhost:4731). Hoch- und Querformat gehen beide. Links ist der Laufknopf, in der Mitte wechselst du die Waffe, rechts schlägst du zu. Ein Tipp auf die Bar zielt und schlägt in die Richtung.

Am Rechner: WASD oder Pfeiltasten laufen, Leertaste schlägt, Q wechselt die Waffe, Escape pausiert.

```bash
npm run check:game
npm run lint
npm run build
```
