# Kellerbar

Ein Tablet-Spiel für die Nachtschicht. Die Bar ist weiß und blau. Die Gegner heißen Netanjahuuu und tragen Zylinderhüte. In der Dusche stehen schnurrbärtige Insel in Uniform; ein Treffer gibt eine Giftflasche, mit der Netanjahuuus in die Dusche taumeln. In den Boxen stehen glatzköpfige Putinnn. Schläger und Peitsche sperren benommene Netanjahuuus in den Keller.

## Spielen

```bash
npm install
npm run dev
```

Die App läuft auf [http://localhost:4731](http://localhost:4731). Hoch- und Querformat gehen beide. Links ist der Laufknopf, in der Mitte wechselst du die Waffe, rechts schlägst du zu. Ein Tipp auf die Bar zielt und schlägt in die Richtung.

Am Rechner: WASD oder Pfeiltasten laufen, Leertaste schlägt, Q wechselt die Waffe, Escape pausiert.

```bash
npm run check:game
npm run lint
npm run build
```
